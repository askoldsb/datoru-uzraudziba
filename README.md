# Automatizēta datoru uzraudzības sistēma

Projekts automatizētas datoru uzraudzības sistēmas izstrādei.

## Statuss

Sistēma darbojas (~30+ datori, NAS + plānotie uzdevumi). Repozitorijs izveidots 2026-11-02 un satur visu apkopoto projektu.

## Struktūra

- `CLAUDE.md` — konteksts darbam ar Claude (lēmumi, konvencijas, pašreizējais stāvoklis)
- `docs/progress.md` — darba žurnāls pa sesijām
- `docs/prasibas.md`, `docs/arhitektura.md`, `docs/darba-procedura.md` — prasības, arhitektūra, procedūras
- `docs/iericu-uzraudziba.md` — ierīču uzskaites atskaites punkts (apturēts)
- `docs/dokumenti/` — Word dokumenti (statusa apraksts, instrukcija, plānojums)
- `src/` — PowerShell skripti (skat. `src/README.md`); `config-piemeri/` — konfigurācijas piemēri
- `docs/github-iestatijumi.md` — GitHub kontu struktūra, limiti un darba kārtība ar Claude
